# Student Attendance System

Консольное приложение для учета посещаемости студентов.

## О проекте

Приложение предназначено для управления студентами, учебными группами и дисциплинами, а также для учета посещаемости занятий.

Проект разработан как учебное консольное приложение на C# с использованием Entity Framework Core и SQLite.

## Технологии

C#, .NET 8, Entity Framework Core 8, SQLite и LINQ.

## Возможности

Приложение позволяет управлять студентами, группами и дисциплинами: просматривать, добавлять, удалять и изменять записи.

Для посещаемости предусмотрено создание занятий, отметка присутствия студентов, просмотр истории и изменение записей.

Также предусмотрена статистика посещаемости студентов, групп и дисциплин.

## Основные сущности

`Student` — студент.

`Group` — учебная группа.

`Subject` — учебная дисциплина.

`GroupSubject` — связь между группой и дисциплиной.

`AttendanceSession` — занятие.

`AttendanceRecord` — запись о посещаемости.

## Запуск

Для запуска требуется установленный .NET 8 SDK.

```bash
dotnet restore
dotnet run
```

## База данных

Для хранения данных используется SQLite. Entity Framework Core используется для взаимодействия приложения с базой данных.

Файл базы данных создается локально и не добавляется в Git.

## Git

Локальная база данных, файлы сборки и системные файлы исключены из репозитория с помощью `.gitignore`.
