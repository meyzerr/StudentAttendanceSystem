# Student Attendance System

Консольное приложение для учета посещаемости студентов.

## О проекте

Приложение позволяет преподавателю управлять студентами, группами, учебными дисциплинами и посещаемостью занятий.

## Технологии

* C#
* .NET 8
* Entity Framework Core 8
* SQLite

## Возможности

* Управление студентами
* Управление группами
* Управление дисциплинами
* Создание занятий
* Учет посещаемости
* Просмотр истории посещаемости
* Редактирование посещаемости
* Просмотр статистики

## Запуск

### Требования

* .NET 8 SDK

### Запуск приложения

```bash
dotnet restore
dotnet run
```

## База данных

Для хранения данных используется SQLite.

Entity Framework Core используется для работы приложения с базой данных.

### Основные сущности

* `Group` — учебная группа
* `Student` — студент
* `Subject` — учебная дисциплина
* `GroupSubject` — связь группы и дисциплины
* `AttendanceSession` — занятие
* `AttendanceRecord` — запись о посещаемости
